# Спокойная уверенность

Сайт маркетингового консалтинга для малого и среднего бизнеса, Минск и Беларусь.

- Основа: #fbfcfa, текст и тёмные поля: #152f42 / #183448.
- Основное действие: зелёный #27694e, поддерживающий фон: #e7efea / #edf2ee.
- Вторичный текст: #61737b; границы: #dce4e3.
- Шрифт: Manrope variable 200–800, локальный файл с кириллицей, OFL.
- Desktop: ширина контента до 1328px, поля 56px. Mobile: поля 16–20px.
- Крупный первый экран, затем блоки с разной плотностью: ситуации, линейный список услуг, схема контекста, последовательность этапов, тёмное поле подхода, FAQ, форма.
- Авторская графика: переход от задачи к следующему шагу и концентрические окружности «бизнес — клиенты — маркетинг». Это объяснение процесса, не показатели роста.
- Знак из двух встречных направлений — временный графический символ; не зарегистрированный логотип.
- Кнопки прямые, радиус 5px. Сдержанные hover/focus; никакого обязательного движения. Reduced motion отключает переходы и плавный скролл.
- Тон: спокойный, понятный, открытый. Без превосходных степеней, вымышленных доказательств и гарантий бизнес-успеха.
- Фото команды отсутствуют: подставлять только реальные материалы владельца. Чужие фотографии и кейсы не используются.
