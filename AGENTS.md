# Работа над сайтом

Проект: маркетинговый консалтинг для малого и среднего бизнеса, Минск и Беларусь.
Сначала прочитайте PROJECT.md, BRAND_BOOK.md и README.md. Согласованное направление — «Спокойная уверенность»; не начинайте исследование и выбор дизайна заново при обычных правках.

Сайт находится в site/. Используйте существующую изолированную копию; не создавайте Git worktree без явной просьбы пользователя. Пакет Website Designer в /workspace/website-designer-agent — справочник, его не изменять и не отправлять туда сайт.

Команды из site/: npm ci, npm run dev, npm run lint, npm test, npm run build. Браузерные проверки: npm run test:browser при работающем сервере. Для системного Chromium используется /usr/bin/chromium; можно задать BROWSER_PATH и TEST_BASE_URL.

Контакты подтверждены владельцем: https://t.me/alexxstudio и +375 25 533 10 12. Услуги: консультация, аудит, стратегия, сопровождение, продвижение, контроль результатов. Не выдумывать название, отзывы, опыт, цены, сроки и гарантии роста.

Ключи только в игнорируемом site/.env.local или защищённых настройках хостинга. Не печатать и не просить их в чате. Без подключений форма возвращает понятную ошибку, без ложного успеха; Telegram и телефон доступны напрямую. До публичного запуска требуются реальные реквизиты оператора, утверждённая политика, домен и тест доставки заявки.

Публикация и push в GitHub выполняются по поручению пользователя. Текущие исходники и сервер среды сами по себе не означают публикацию.
