## Реализованный срез

- Верхнее и мобильное меню; переходы из рабочего раздела к блокам главной.
- Серверная проверка пароля scrypt, подписанная HttpOnly/SameSite Strict cookie,
  выход, срок сеанса2ч, отклонение запросов без входа и с чужого Origin.
- JPEG/PNG до25МБ в браузере → ориентированный PNG без EXIF, сторона до1800px,
  передача до3МБ → закрытый фиксированный Space → проверенный исходный OCR-текст.
- NDJSON статусы, таймаут50с, отмена без автоматического повторного GPU-вызова.
- Проверка SHA-256, модели/ревизии, отсутствие автоматического подтверждения SKU.
- Экспорт текста в CSV и JSON; нейтрализация формул Excel в CSV.

Это первый web-срез: один тестовый ценник. Полная Python-таблица SKU, локальная
SQLite-история и пакетное видео здесь не перенесены. Изображения не хранятся в
базе сайта; временный приём/кэш действует у HF. История результата живёт в текущей
странице браузера до обновления/выхода; при необходимости скачайте JSON/CSV.
Текст модели требует проверки. Опечатки валюты могут встречаться.

## Серверные настройки Vercel

Существующий проект site_shop_work-dk21, Root Directory site. Добавить только
в Production и отметить Sensitive:

- RECOGNITION_PASSWORD_HASH — приватный verifier scrypt1:salt:hash, уже подготовлен
  в игнорируемом site/.env.local. Исходный пароль в коде/репозитории не хранится.
- SHELFDATA_HF_TOKEN — существующий read token к Tihonov1981/deepseec1981.

Токен не должен иметь префикс NEXT_PUBLIC_. Не загружать DPAPI-файл в Vercel:
его расшифровывает только Windows-профиль. Для безопасного ручного переноса двух
значений можно открыть configure-vercel-secrets.cmd: значения копируются по одному
в буфер обмена, без отображения и записи в новый файл. Вставлять только в
серверные переменные указанного проекта. После переноса закрыть окно помощника.
Затем развернуть новую версию. Другие ключи/форму заявок/Telegram не менять.

Без verifier вход закрыт; без HFtoken облачный вызов недоступен. Не делать
общедоступный fallback и не сохранять пароль/токен в tracked .env.production.
Смена verifier завершает старые сеансы. Дневную GPU-квоту задаёт Hugging Face.

Ограничения защиты: лимит5 попыток за10мин и один активный OCR — на инстанс
сервера, не глобальный distributed rate limiter. Shared password не даёт личных
ролей/аудита пользователей; отдельные аккаунты — следующий срез.
