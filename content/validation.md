# Проверки сайта

Дата: 20 октября 2026. Проверялась текущая сборка в облачной среде, без публикации.

## Пройдено

- Повторная установка по lockfile: `npm ci --no-audit --no-fund`.
- ESLint: `npm run lint`, без ошибок.
- TypeScript и производственная сборка: `npm run build`, без ошибок.
- `npm test`: 5 тестов, 5 пройдено, 0 пропусков. Проверены валидация/спам, обязательное согласие, отсутствие ложного успеха, сбой одного/обоих каналов и резервная доставка. Внешние каналы в этих тестах заменены управляемыми функциями.
- Производственный сервер запущен и функционально проверен по HTTP.
- Браузерный сценарий пройден на 1440×900, 1920×1080, 390×844, 320×640: нет горизонтального переполнения, загружен локальный Manrope, один H1, 6 услуг, правильные Telegram/телефон.
- Меню мобильной версии открывается, закрывается по Escape и после перехода; выбор ситуации или услуги заполняет описание задачи; FAQ открывается.
- FAQ в JSON-LD совпадает с видимым содержанием. Основной текст доступен без JavaScript. Проверен reduced-motion.
- Неподключённая форма сообщает о недоступности и предлагает Telegram; успешная отправка не имитируется.
- Отдельные HTTP-проверки: пустые/неверные данные, неверный JSON, нет согласия, заполненная ловушка → 400; чужой Origin → 403; шестая попытка за окно → 429; валидная заявка без подключений → 503.
- GET /privacy, /robots.txt, /sitemap.xml, /llms.txt, /og.png, /icon.svg → 200. Неизвестная страница → 404.
- Визуально просмотрены desktop и mobile; исправлены отсутствовавшие глифы стрелок и увеличены мелкие подписи. Горизонтального переполнения после правок нет.

Снимки и результаты: content/previews/. HTML-просмотр содержит текст и оформление текущей страницы, локальные стили/шрифты и простое меню. Он не заменяет сервер Next.js и не отправляет заявки.

## Не подключено / не проверено

- Реальная запись в Supabase и уведомление Telegram: в среде нет нужных серверных переменных. Секретные значения не запрашивались и не выводились.
- Оператор данных и итоговые условия /privacy ещё не утверждены. LEAD_INTAKE_ENABLED по умолчанию выключен. До включения нужно доработать документ под фактическую организацию.
- Название компании, домен и хостинг пока не определены. Без SITE_URL sitemap намеренно пуст; абсолютные canonical/OG будут настроены при выборе домена.
- Сайт не опубликован; публичная доступность и действия с реального телефона после публикации не проверялись. Проверены ссылки и их адреса, но не звонок и не переписка с клиентами.
- Исходники находятся в текущей копии среды; push в GitHub не выполнялся.

Наличие рабочего сайта для просмотра и прямых контактов не означает готовность внешних интеграций к приёму персональных данных.

HTML-просмотр дополнительно проверен загрузкой содержимого в Chromium: 6 услуг, мобильное меню, встроенный Manrope и отсутствие внешних запросов. Прямое открытие file:// блокируется политикой браузера облачной среды; это не использовалось как проверка. HTML можно скачать и открыть на своём устройстве.
